* update /etc/exports file:

The NFS server must be configured to export the desired directory, typically using the /etc/exports file, and the exports must be re-exported with

#+begin_src bash
exportfs -arv
#+end_src

* check mount (in server)

 #+begin_src bash
sudo showmount -e
 #+end_src
