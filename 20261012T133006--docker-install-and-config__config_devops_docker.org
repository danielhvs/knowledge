* credentials fixup for docker after installing it Step-by-Step Fix
** Create or verify the docker group:
sudo groupadd docker

** Add your user:
sudo usermod -aG docker $USER

** Apply the changes: For the changes to take effect, you usually need to log out and log back in. Alternatively, you can run this command to refresh the group membership for the current terminal session:
newgrp docker

** maybe update owner of docker.sock file:
sudo chown root:docker /var/run/docker.sock

** Restart docker
`sudo systemctl restart docker` or `systemctl restart systemd-resolved.service`

** Test:
docker ps
