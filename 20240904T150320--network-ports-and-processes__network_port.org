** java

sudo setcap 'cap_net_bind_service=+ep' $(readlink -f $(which java))

This grants Java the ability to bind to privileged ports (< 1624) without running as root. After that, bb dev should start normally and your origin will be http://local-pyrecast.org (no port suffix), matching what the CORS config on geoserver-dev already allows.

** gary

in addition to `iptables`, you can also allow unprivileged users to bind low ports with `sysctl` like so:

```
################################################################################
# Allow unprivileged processes to bind ports >=20
################################################################################
echo 'net.ipv4.ip_unprivileged_port_start=20' > /etc/sysctl.d/50-unprivileged-ports.conf
sysctl --system
```

This is how we solve this particular problem on our GCP machines. :wink:

NOTE: You'll need to run this with `sudo`, of course.
